# Многопоточный сервер задач

Домашнее задание по теме TCP-сокетов, многопоточности и синхронизации общих данных.

## Файлы

- `server.py` — многопоточный TCP-сервер.
- `client.py` — клиент приложения.
- `protocol.py` — протокол обмена сообщениями по TCP.
- `README.md` — описание проекта.

## Запуск

Сначала запустить сервер:

```bash
python server.py
```

Затем в другом терминале запустить клиента:

```bash
python client.py
```

Для проверки многопоточности можно открыть несколько терминалов и запустить несколько клиентов одновременно.

## Команды

```text
/add <text>       добавить задачу
/list             показать все задачи
/done <number>    отметить задачу выполненной
/quit             завершить работу клиента
```

Дополнительно реализована команда:

```text
/delete <number>  удалить задачу
```

## Пример

Клиент 1:

```text
> /add Купить кофе
Задача добавлена: 1. [ ] Купить кофе
```

Клиент 2:

```text
> /list

1. [ ] Купить кофе
```

Клиент 2:

```text
> /done 1
Задача выполнена: 1. [x] Купить кофе
```

После этого клиент 1 также увидит выполненную задачу при `/list`.

## Многопоточность

После подключения каждого клиента сервер создаёт отдельный поток:

```python
threading.Thread(
    target=handle_client,
    args=(client_sock, addr),
    daemon=True
).start()
```

Поэтому несколько клиентов могут работать одновременно.

## Общие данные

Все задачи находятся в одном списке на сервере:

```python
tasks = []
```

Клиенты не хранят собственные копии списка. Поэтому изменение задачи одним клиентом видно остальным клиентам.

## Синхронизация

Для безопасной работы нескольких потоков с общим списком используется:

```python
tasks_lock = threading.Lock()
```

Доступ к списку при изменении и чтении защищён конструкцией:

```python
with tasks_lock:
    ...
```

Это предотвращает одновременное изменение списка несколькими потоками и обеспечивает корректную работу общего состояния.

## Обработка ошибок

Обрабатываются:

- неизвестные команды;
- `/add` без текста;
- `/done` без номера;
- `/done` с нечисловым значением;
- несуществующий номер задачи;
- `/delete` без номера;
- `/delete` с нечисловым значением;
- потеря соединения с клиентом.

## Требования задания

- TCP-сокеты — выполнено.
- `threading` — выполнено.
- Общий изменяемый список — выполнено.
- Синхронизация через `threading.Lock` — выполнено.
- Несколько клиентов — выполнено.
- Общий список задач для всех клиентов — выполнено.
- Обработка ошибок — выполнено.
- Дополнительная команда `/delete` — выполнено.
