# Многопоточный сервер задач

Программа для создания и управления списком задач.

## Запуск

Сначала запускается сервер:

python3 server.py

После этого в другом терминале запускается клиент:

python3 client.py

Можно запустить несколько клиентов одновременно.

## Команды

/add <текст> — добавить новую задачу

/list — показать все задачи

/done <номер> — отметить задачу как выполненную

/quit — завершить работу клиента

Дополнительно:

/delete <номер> — удалить задачу

## Как работает программа

Сервер работает через TCP-соединение.

Все задачи хранятся на сервере в одном общем списке. Поэтому если один клиент добавляет задачу, другие клиенты тоже могут её увидеть.

Для каждого подключённого клиента создаётся отдельный поток с помощью threading.

Для безопасной работы нескольких потоков с общим списком используется threading.Lock().

## Обработка ошибок

Программа обрабатывает неправильные команды, пустой /add, неправильный номер задачи и ситуацию, когда задачи с таким номером нет.

## Проверка

Программа была проверена с двумя клиентами одновременно. Один клиент добавил задачу, а второй смог увидеть её в общем списке и отметить выполненной.
